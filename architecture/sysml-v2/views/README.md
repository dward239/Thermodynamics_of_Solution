# SysML v1-style views of a SysML v2 software model

The authoritative **software architecture intention** is expressed in SysML v2
textual constructs. The linked diagrams are **Mermaid visualizations** organized
using the familiar SysML v1 diagram taxonomy, for easier engineering review.

| SysML v1 analogue | Visual view | SysML v2 constructs |
| --- | --- | --- |
| BDD | [Block definitions](01-bdd.md) | part def / typed attributes |
| IBD | [Internal connected parts](02-ibd.md) | part, port def, connect |
| ACT | [Adaptive time-step activity](03-activity.md) | action def, succession |
| STM | [Simulation state machine](04-state-machine.md) | state def, transition |
| SD | [Solver call sequence](05-sequence.md) | Software interaction ordering |
| REQ | [Requirements and verification](06-requirements.md) | requirement def, verification intent |
| PAR | [Mass/energy constraints](07-parametric.md) | Constraints, invariant equations |
| Allocation | [Functional allocation](08-allocation.md) | allocation def / allocate |
| Chemical time coupling | [Accepted-state chemistry IBD/ACT/STM/SD](09-chemistry-time-coupling.md) | part, port, connect, action def, state def |

**Textual SysML v2 sources:** [structural model](../RadioThermochemicalArchitecture.sysml),
[connected interfaces](../TimeIntegrationConnections.sysml),
[actions and state machine](../TimeIntegrationBehavior.sysml), and
[requirements](../TimeIntegrationRequirements.sysml). The
[traceability matrix](../requirements-traceability.md) maps requirements to
C++ APIs/tests.

These are **not** native SysML v1 diagrams or autogenerated views from
SysML v2. GitHub renders Markdown Mermaid diagrams; SysML v2 text is not
machine-parsed in CI yet. Connections show software data exchange, not
physical matter-flow ports or piping.

The accepted-state chemical projection adds a **one-way optional**
connection shown in [09-chemistry-time-coupling.md](09-chemistry-time-coupling.md).
Textual source: [ChemistryTimeCoupling.sysml](../ChemistryTimeCoupling.sysml).
